# 煲珠公卡牌配方

煲珠公卡牌配方查询 Web 程序，非真实可商用配方，仅供微信小程序煲珠公点单-我的-煲珠公卡牌游戏里查询使用。

主页默认展示煲珠公卡牌游戏里当前上架可合成的所有配方，亦可根据选择的卡牌手动搜索相应的配方。

## 🛠️ 技术栈

*   **前端基础**：HTML5, Vanilla JavaScript (原生 JS), CSS3
*   **数据库引擎**：[sql.js](https://github.com) (SQLite WebAssembly v1.12.0)
