# 煲珠公卡牌配方

煲珠公卡牌配方在线查询 Web 程序，非真实可商用配方，仅供微信小程序煲珠公点单-我的-煲珠公卡牌游戏里查询使用。

## 在线体验

https://bxjt123.github.io/bzgCard/

## 使用方法

*   主页默认展示煲珠公卡牌里当前上架可合成的所有配方。
*   右上角搜索，选择某张或某些卡牌后，可搜索包含或不含所选任一卡牌的配方。
*   右上角已下架配方，可查询部分已下架的配方，非所有已下架的配方。
*   更新日志，可查看近期配方、卡牌或程序功能的一些变动更新。

## 技术栈

*   **前端**：HTML5, JavaScript, CSS3, Layui
*   **数据库**：SQLite
